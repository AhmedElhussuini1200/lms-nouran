# منصة التعلم - Learning Management System

## نظرة عامة

منصة تعليمية شاملة تحتوي على:
- تسجيل الدخول والخروج
- نظام إشعارات
- معلم واحد: مستر عصام سمكة
- طلاب من الصفوف: 1 ثانوي، 2 ثانوي، 3 ثانوي
- حصص دراسية
- واجبات
- امتحانات
- فيديوهات تعليمية
- متابعة من ولي الأمر

## المميزات

### للمعلم:
- إدارة الحصص الدراسية
- إضافة وتعديل الواجبات
- إنشاء الامتحانات
- رفع الفيديوهات التعليمية
- متابعة أداء الطلاب

### للطالب:
- مشاهدة الحصص
- متابعة الواجبات وتسليمها
- تقديم الامتحانات
- مشاهدة الفيديوهات التعليمية

### لولي الأمر:
- متابعة أداء الأبناء
- عرض الواجبات والامتحانات
- الاطلاع على النتائج

## التثبيت والإعداد

### 1. تثبيت المتطلبات
```bash
composer install
npm install
```

### 2. إعداد قاعدة البيانات
```bash
# نسخ ملف البيئة
cp .env.example .env

# إنشاء مفتاح التطبيق
php artisan key:generate

# تشغيل الـ Migrations
php artisan migrate

# تشغيل الـ Seeders لإضافة المعلم
php artisan db:seed
```

### 3. إنشاء رابط التخزين
```bash
php artisan storage:link
```

### 4. تشغيل التطبيق
```bash
# في terminal واحد
php artisan serve

# في terminal آخر
npm run dev
```

## بيانات الدخول الافتراضية

### المعلم:
- **البريد الإلكتروني:** teacher@lms.com
- **كلمة المرور:** password

## هيكل قاعدة البيانات

### الجداول الرئيسية:
- `users` - المستخدمون (معلم، طالب، ولي أمر)
- `courses` - الحصص الدراسية
- `assignments` - الواجبات
- `exams` - الامتحانات
- `videos` - الفيديوهات التعليمية
- `notifications` - الإشعارات
- `assignment_submissions` - تسليمات الواجبات
- `exam_results` - نتائج الامتحانات
- `student_parent` - ربط الطلاب بأولياء الأمور

## الأدوار (Roles)

1. **teacher** - المعلم
2. **student** - الطالب
3. **parent** - ولي الأمر

## الصفوف الدراسية

- `1_secondary` - الأول الثانوي
- `2_secondary` - الثاني الثانوي
- `3_secondary` - الثالث الثانوي

## المسارات (Routes)

### المصادقة:
- `GET /login` - صفحة تسجيل الدخول
- `POST /login` - تسجيل الدخول
- `POST /logout` - تسجيل الخروج

### لوحة التحكم:
- `GET /dashboard` - لوحة التحكم (تختلف حسب الدور)

### الحصص:
- `GET /courses` - قائمة الحصص
- `GET /courses/{course}` - عرض حصة

### الواجبات:
- `GET /assignments` - قائمة الواجبات
- `GET /assignments/{assignment}` - عرض واجب

### الامتحانات:
- `GET /exams` - قائمة الامتحانات
- `GET /exams/{exam}` - عرض امتحان

### الفيديوهات:
- `GET /videos` - قائمة الفيديوهات
- `GET /videos/{video}` - مشاهدة فيديو

### الإشعارات:
- `GET /notifications` - قائمة الإشعارات
- `POST /notifications/{notification}/read` - تحديد إشعار كمقروء
- `POST /notifications/read-all` - تحديد الكل كمقروء
